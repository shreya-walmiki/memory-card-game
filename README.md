# Memory Card Game 🃏

A fun and interactive browser-based Memory Card Game where players flip cards and find matching pairs.

## Features
- Interactive card flipping
- Match identical cards
- Simple and colorful user interface
- Improves memory and concentration
- Built with HTML, CSS, and JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open the `index.html` file.
4. Right-click and select **Open with Live Server**.

Alternatively, run the following command in the VS Code terminal:

```bash
python -m http.server 8000
```

5. Open `http://localhost:8000` in your browser.
                     OR
6. Open project in VS CODE and open new terminal and give command: start index.html
## How to Play
1. Double-click on a card to reveal it.
2. Find another card with the same image.
3. Match all pairs to complete the game.

Enjoy playing!
